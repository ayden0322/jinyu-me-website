## ⚠️ 動工前需業主確認的 3 件事

### 1. 業務範疇真實邊界
強電 / 弱電 / 空調 / 給排水 / 消防 — 這 5 大類是「全部都接」還是「強電為主、其他配合」？
- 影響「服務項目」6 卡的排序與文案承諾力道
- 若業主僅承接部分項目，未承接的卡片需刪除或改寫為「合作夥伴提供」

### 2. 彰化兆富案場資訊
除了浮水印上已可見的「彰化兆富 / 出線盒整理」之外，可否再提供：
- 完工年份（或預計完工日期）
- 工程總類別（強電？弱電？整廠機電？）
- 業主是否同意正式列為公開案例

### 3. 服務時間
「週一至週六 09:00 – 18:00（緊急搶修不限）」目前為預設值，
請業主確認實際營業時段。
